Overview

Majority of the labor force conduct office-like, administrative work, and this population includes to academia as well, where students spend prolonged duration sitting and studying for courses. This project is a cushion-like product aimed at helping consumers track their posture, through the deployment of a machine learning model on an embedded system device.

More technical details about the project can be found in this GitHub Repository

Final Device Design

Outcome

The neural network on the cushion is able to make predictions based on incoming sensor data. Depending on what the model predicts, the respective timer counts for good and bad posture are incremented respectively. 0 = Bad, 1 = Good.

Design Process

The original project did not start with an embedded machine learning model. After initial testing, the noise present in the sensor readings were not ideal for manual computations done by us, which would then entail a lot of computations since there are many ways to achieve a good posture.

After initial testing, some sensors were deemed infeasible and removed after the first iteration(the flex sensor). Our accuracy started around 70%, and we achieved up to 97% accuracy now using further feature engineering, value scaling, and adding more layers in the neural network since memory permits. We also collected more data samples to improve generalizability of the learned weights by the nueral network.
