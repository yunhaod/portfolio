Overview

This project improves home security by notifying homeowners of any intrusion detected by a motion sensor. Upon connecting and subscribing via the app, messages appear indicating whether a threat has been detected.

More details can be found in the GitHub Repository.

Outcome

The app successfully receives sensor messages from the client upon any updates.

Introduction

This project uses MQTT (Message Queuing Telemetry Transport) to transmit messages between clients. MQTT is a lightweight IoT messaging protocol ideal for remote device communication. The MQTT broker is responsible for relaying messages across topics within the network.

Local MQTT Broker Output

Iterations

The first few iterations tested functionality on a local MQTT broker running from my computer. After validating the system, the broker was hosted over the internet with an authentication layer to allow only authorized users.

Messages appeared after subscribing, shown in the output console for the initial app design. In the final version, most buttons are hidden until the MQTT Manager is connected to the broker, to prevent API misuse.

Hardware

An ESP32 was chosen to process sensor data and connect to the MQTT broker. The microcontroller detects intrusions using a hall effect sensor.

A magnet is attached to the door — when it swings open, the sensor picks up the event and notifies the homeowner.

The warning persists until the app publishes an acknowledgement message.

To dismiss the warning, an acknowledgement message must be sent from the app.

Takeaways

Through this project I deepened my understanding of IoT protocols, authentication systems, and backend integration in Swift. I gained comprehensive insight into the fundamentals of MQTT and how to integrate it into real-world applications.
